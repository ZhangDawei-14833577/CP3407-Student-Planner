# CP3407 Student Assignment and Study Planner

A web-based assignment and study planning system developed for the
CP3407 Advanced Software Engineering project at James Cook University.

## Project Overview

The Student Assignment and Study Planner is designed to help university
students organise their courses, assessments, study tasks and deadlines
in one centralised system.

Students often manage academic information across learning platforms,
emails, calendars and personal notes. This project aims to provide a
simple and structured web application where students can record their
academic responsibilities and monitor their progress.

## Project Objectives

- Provide a central location for managing courses and assessments.
- Help students record and monitor assignment and examination deadlines.
- Allow students to create and manage study tasks.
- Support task prioritisation and completion tracking.
- Provide a dashboard summarising upcoming and completed work.
- Develop the system using an iterative Agile software engineering process.

## Planned Core Features

- User registration
- User login and logout
- Course management
- Assessment management
- Study task management
- Due dates and priorities
- Task completion tracking
- Search, filtering and sorting
- Student dashboard
- Progress summary
