# Online Forum User Research Plan

## Project

Student Assignment and Study Planner

## 1. Purpose

The purpose of this research is to collect feedback and identify common
requirements from university students discussing how they manage
courses, assessments, examinations, deadlines and study tasks.

The findings will be used to refine the project requirements, user
stories and product backlog for the Student Assignment and Study Planner.

This research uses publicly available online forum discussions instead
of conducting direct face-to-face interviews.

## 2. Research Objectives

The research aims to identify:

- How university students currently record assignments and deadlines
- Problems students experience with existing planning methods
- Features students consider useful in a study-planning application
- Features that students consider inconvenient or unnecessary
- Information that should appear on the application dashboard
- Common preferences for reminders, priorities, filters and task status
- Additional requirements that were not included in the initial backlog

## 3. Target User Group

The target user group is university students who manage multiple:

- Courses
- Assignments
- Examinations
- Practical activities
- Study tasks
- Academic deadlines

The research will focus on forum discussions written by current or
recent university students.

## 4. Data Sources

Publicly available discussions will be reviewed from online student
communities, including:

- Reddit r/college
- Reddit r/adhd_college
- Reddit r/GetStudying
- Reddit r/StudentNurse
- The Student Room university discussion forums

The research will focus on discussions concerning:

- Assignment tracking
- Academic deadlines
- Student planners
- Study organisation
- Task-management applications
- Reminder systems
- University workload management

## 5. Search Terms

The following search terms will be used:

- keep track of university assignments
- assignment planner for college students
- managing assignment deadlines
- student study planner
- university deadline reminder
- assignment tracker spreadsheet
- best way to organise college assignments
- student planner too complicated
- breaking assignments into smaller tasks
- university dashboard planner features

## 6. Source Selection Criteria

A forum post or discussion may be included when it:

- Is publicly accessible
- Discusses university or college study
- Describes a real planning method or problem
- Discusses assignments, examinations or deadlines
- Suggests a feature or improvement for a planning system
- Contains enough detail to identify a software requirement

A forum post will be excluded when it:

- Is primarily an advertisement
- Promotes academic cheating or paid assignment completion
- Does not relate to university study planning
- Contains no usable information about user needs
- Duplicates another selected discussion
- Contains mainly promotional or automatically generated content

## 7. Planned Sample

The research will review approximately:

- 8–12 relevant forum discussions
- Discussions from at least three online communities
- Multiple comments where they provide useful additional information

The research will focus on recurring patterns rather than treating every
individual comment as a separate requirement.

## 8. Research Method

The research will use qualitative content analysis.

For each selected forum discussion, the following information will be
recorded:

- Source code, such as F01 or F02
- Forum or community name
- Discussion topic
- Current planning method described
- Main problem described
- Requested or recommended feature
- Feature considered inconvenient
- Relevant requirement derived from the discussion
- Date accessed

The original username will not be recorded in the project report.

Forum comments will be paraphrased rather than copied in full.

## 9. Research Questions

The selected forum discussions will be analysed using the following
research questions:

1. How do students currently keep track of assignments, examinations and
   deadlines?

2. What problems do students experience with their current planning
   methods?

3. Why do students miss or nearly miss academic deadlines?

4. What information do students want to record for each course?

5. What information do students want to record for assignments and
   examinations?

6. Do students find it useful to divide a large assignment into smaller
   study tasks?

7. How do students prefer tasks to be prioritised?

8. What information should appear on the main dashboard?

9. Which search, filtering and sorting options are useful?

10. What types of reminders do students prefer?

11. Do students consider progress statistics or charts useful?

12. Which planning features create unnecessary complexity?

13. Which additional features are commonly requested?

## 10. Initial Feature Categories

The forum findings will be compared with the following proposed core
features:

- User registration and login
- Course management
- Assessment management
- Study task management
- Due dates
- Priorities
- Completion status
- Search and filtering
- Dashboard
- Progress summary

Possible additional feature categories include:

- Course colour coding
- Assessment weighting
- Estimated task effort
- Reminder preferences
- Weekly workload view
- Overdue-task identification
- Task breakdown
- Calendar view
- Grade tracking

## 11. Data Analysis

The forum findings will be grouped into the following categories:

### Current Planning Methods

Examples may include:

- Learning management systems
- Digital calendars
- Paper planners
- Spreadsheets
- To-do list applications
- Notes applications
- Whiteboards

### User Problems

Examples may include:

- Information distributed across multiple systems
- Forgotten deadlines
- Ignored notifications
- Excessive manual data entry
- Planning applications that are too complex
- Difficulty deciding what task to complete next
- Difficulty starting large assignments

### Requested Features

Examples may include:

- Central dashboard
- Course organisation
- Due-date tracking
- Task priorities
- Task status
- Assignment breakdown
- Search and filtering
- Configurable reminders
- Weekly overview

### Scope Decisions

Each identified requirement will be classified as:

- Core requirement
- Medium-priority requirement
- Optional extension
- Out of scope

## 12. Ethical and Privacy Considerations

- Only publicly accessible forum discussions will be used.
- Private groups and private messages will not be accessed.
- Forum usernames will not be included in the project documentation.
- Participants will be identified using source codes such as F01 and F02.
- Posts will be paraphrased rather than reproduced in full.
- Sensitive personal information will not be recorded.
- The findings will only be used for the CP3407 software project.
- Synthetic personas will be clearly identified as synthetic and will
  not be presented as real interview participants.

## 13. Expected Outputs

The research will produce:

- A forum source log
- A summary of recurring user problems
- A summary of commonly requested features
- Refined software requirements
- Refined user stories
- Priority values of 10, 20, 30, 40 or 50
- Estimated effort in development days
- An updated product backlog
- Justification for project scope decisions

## 14. Relationship to the Initial Backlog

The initial backlog contains preliminary ideas created before the user
research.

After the forum research:

- Existing user stories may be revised
- Missing user stories may be added
- Low-value features may be reduced in priority
- Complex features may be moved outside the core scope
- Priorities and effort estimates will be added
